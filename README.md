# Berlin Housing Market Analysis

##Project Overview
This project analyzes the Berlin rental market using real listing data from 2020 to 2026. The goal is to understand rental price patterns, district differences and trends over time.

*Main focus: Rental prices (Kaltmiete), rent per m2, and neighborhood differences.

##Dataset
- Source: Berlin Real Estate Sales & Rentals 2020-2026, Kaggle.
- Main file used: 'rentals.csv' (30,000 listings)
- Key Variables: Cold rent, rent per m2, size, rooms, district(bezirk), and neighborhood (Ortsteil)

- #Key Insights.
- Average cold rent = 947 eur.
- Average rent per m2 = 12.12 eur (rising above 14 eur by late 2025).
- Friedrichshain has the highest average rents,
- Smaller apartments tend to have higher rent per square meter.
- Clear upward trend in rental prices over the years.
- Highest number of listings in Reinickendorf, Treptow-Kopenick and Pankow.
